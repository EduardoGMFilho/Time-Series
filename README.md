# Séries Temporais


Repositório desenvolvido no contexto da disciplina de Séries Temporais, com foco na aplicação prática de técnicas de Análise de Dados, Análise Preditiva e Aprendizagem de Máquina aplicadas a dados reais, especialmente do mercado financeiro.

O objetivo principal do repositório é consolidar conceitos teóricos por meio de experimentos computacionais, explorando diferentes abordagens estatísticas e modelos de aprendizado supervisionado e profundo.

🎯 Objetivos do Repositório

Aplicar conceitos fundamentais de Séries Temporais em problemas reais

Realizar análise exploratória de dados (EDA) para identificação de padrões temporais

Desenvolver modelos de previsão e classificação

Comparar abordagens tradicionais e modelos baseados em Redes Neurais

Consolidar conhecimentos práticos em Machine Learning aplicado a dados temporais

🧠 Tópicos e Técnicas Abordadas

Os projetos presentes neste repositório contemplam os seguintes tópicos:

📊 Análise de Dados
Limpeza, transformação e visualização de séries temporais

🔮 Análise Preditiva
Modelagem e previsão de valores futuros com base em dados históricos

🤖 Aprendizagem de Máquina (Machine Learning)
Aplicação de algoritmos supervisionados para previsão e classificação

🧮 Regressão Logística
Utilizada em problemas de classificação relacionados a eventos financeiros

🧠 Redes Neurais Artificiais
Modelos baseados em redes neurais para captura de padrões não lineares

🔁 LSTM (Long Short-Term Memory)
Redes neurais recorrentes aplicadas especificamente a séries temporais
